# Data Files Directory

Place your CSV files here:

1. sales_cleaned.csv - Main transaction data
2. product_summary.csv - Product information
3. customer_summary.csv - Customer information
4. daily_sales.csv - Daily aggregated sales
5. monthly_sales.csv - Monthly aggregated sales
6. product_daily_sales.csv - Product-level daily sales

The import_data.py script will read these files and populate MongoDB collections.
